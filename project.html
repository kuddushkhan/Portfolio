Posture Pro

AI-Based Exercise Posture Detection & Analysis

Posture Pro is an AI-powered exercise posture analysis system designed to help users improve their exercise form through computer vision and pose detection.

Explore Project Back Home

01 — ABOUT

About the Project

Posture Pro is a computer vision based system that analyzes exercise videos and provides feedback about the user's posture.

Instead of requiring a live webcam, the current version allows users to upload an exercise video. The system processes the video frame by frame and analyzes body positioning.

Currently, the project focuses on squat posture analysis, identifying whether the posture is correct or incorrect throughout the exercise.

Core Objective

Analyze exercise posture using AI and computer vision techniques and provide useful visual feedback to the user.

02 — PROCESS

How It Works

01

Upload Video

The user uploads an exercise video to the system.

02

Video Processing

The uploaded video is processed frame by frame.

03

Pose Detection

MediaPipe detects important body landmarks from each frame.

04

Posture Analysis

Body positioning is analyzed to determine posture quality.

05

Feedback

Correct and incorrect posture is identified throughout the exercise.

06

Output Video

The system generates a processed video with posture feedback.
