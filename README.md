## 📂 Featured Project

### 🏋️ Posture Pro

**Posture Pro** is an AI-powered exercise posture analysis system that uses computer vision and pose detection to analyze exercise videos.

The current version focuses on **squat posture analysis**.

### Key Features

- Upload exercise videos
- Frame-by-frame video processing
- Human pose detection
- Squat posture analysis
- Correct/incorrect posture detection
- Processed output video with feedback

### Technologies Used

- Python
- MediaPipe
- OpenCV
- FastAPI
- HTML
- CSS
